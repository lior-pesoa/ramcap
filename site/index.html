Set a memory limit for Chrome.

RAMcap lives in your Mac’s menu bar and watches how much memory Chrome uses. When Chrome hits your limit, it stops the largest tab before macOS runs out of memory and freezes everything.

Chrome has no memory limit. Now it has one.

Chrome reached 30.5 GB on a 24 GB Mac, and macOS paused every app: “Your system has run out of application memory.” One runaway tab is enough.

Memory Saver helps, but it only puts idle tabs to sleep. It never touches the tab you’re using, a tab playing video, or one in a call, so it can’t stop a runaway. RAMcap sets a ceiling and keeps Chrome under it.

How it works

RAMcap adds up the real memory of every Chrome process every 15 seconds, the same number Activity Monitor shows. The defaults scale with your Mac’s memory; drag the slider to change them.

  1. A warning at half your RAM

    Chrome passes 12 GB on a 24 GB Mac and you get a notification. Nothing is stopped.

  2. 20 seconds’ notice at the limit

    At 16 GB RAMcap picks the largest tab and tells you. Click Protect to keep it, or Stop now.

  3. The tab is stopped

    If Chrome is still over the limit, that tab’s process ends. It stays open as “Aw, Snap”; reload it to bring it back.

See which tab is which, and protect the ones that matter.

macOS doesn’t tell apps which Chrome tab lives in which process. Turn on tab names and RAMcap reads the titles from Chrome’s own Task Manager, so the menu shows Figma: Design file, 1.01 GB instead of a process ID.

Pin a tab and RAMcap never stops it. Tab names are optional: they need Accessibility permission, and the setup window walks you through it. RAMcap reads tab titles, memory and process IDs, nothing else, and nothing leaves your Mac.

What to know before you install

  • It stops tabs, it doesn’t sleep them. Anything unsaved in a stopped tab is lost. Protect tabs you can’t lose.
  • It can’t tell which tab is in front. The largest tab goes even if you’re looking at it, which is what the 20 seconds are for.
  • One process can hold several tabs of the same site. Stopping it closes all of them, and the menu says so.
  • Tab names need Chrome in English and may break when Chrome changes its Task Manager. Everything else keeps working without them.
  • Google Chrome only, for now. Arc, Brave and Edge are planned.

Questions

How do I limit Chrome’s memory usage on a Mac?

Chrome has no setting for a memory limit. Install RAMcap, a free menu bar app, and set a limit with its slider (by default 65% of your Mac’s RAM, for example 16 GB on a 24 GB Mac). When Chrome’s total memory reaches the limit, RAMcap gives you 20 seconds’ notice and then stops the largest tab’s process.

Why does my Mac say “Your system has run out of application memory”?

macOS shows this when apps together use more memory than your Mac has, even with swap. Google Chrome is a common cause: one heavy tab can grow to many gigabytes. Quit or reload the biggest tabs to recover. To keep it from happening again, cap Chrome’s memory with RAMcap.

Isn’t Chrome’s Memory Saver enough?

Memory Saver puts idle tabs to sleep, which lowers Chrome’s usual memory. It is not a limit: it skips the tab you are using, tabs playing audio or video, tabs in a call and tabs with unsaved input, so a runaway tab can still use all your memory. RAMcap works alongside Memory Saver and adds the ceiling.

What happens to a tab RAMcap stops?

The tab stays open and shows Chrome’s “Aw, Snap” page. Reload it to load the page again. Anything unsaved in that tab, such as a half-written form, is lost, so protect tabs you can’t lose.

Can I stop RAMcap from closing a specific tab?

Yes. When RAMcap is about to stop a tab, the notification has a Protect button. With tab names turned on, you can also pin any tab in the menu so RAMcap never stops it.

Is RAMcap free and safe?

Yes. RAMcap is free and open source under the MIT license, signed and notarized by Apple, and needs no admin password. It only reads memory figures and, if you turn on tab names, tab titles. Nothing leaves your Mac.

Does RAMcap work with Safari, Arc, Brave or Edge?

Not yet. RAMcap works with Google Chrome on macOS 14 or later. Support for Arc, Brave and Edge, which are built on Chromium, is planned.

Download the zip, unzip it and move RAMcap to Applications. Or use Homebrew; it asks you to trust the tap once.
